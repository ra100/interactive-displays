# Interactive Display System - Team Roles & Skills

## 1. Server Developer

**Focus:** Real-time backend infrastructure

**Skills:**
- TypeScript/Node.js
- Fastify HTTP framework
- Socket.io WebSocket implementation
- JSON file persistence
- Real-time state broadcasting

**Responsibilities:**
- WebSocket server implementation
- Layout CRUD operations
- Global state management
- Client connection tracking

---

## 2. Component Developer

**Focus:** Visual element library

**Skills:**
- React 19 functional components
- CSS custom properties (variables)
- CSS animations (keyframes, transitions)
- SVG for curved shapes (elbows)
- Touch event handling

**Responsibilities:**
- 5 core elements (Elbow, Bar, Frame, Button, Text)
- State-responsive color transitions
- 60px touch targets
- Theme-agnostic styling

---

## 3. Builder Developer

**Focus:** Visual layout editor

**Skills:**
- React drag-drop (@dnd-kit)
- Grid-based positioning
- Undo/redo patterns
- Form state management
- WebSocket client integration

**Responsibilities:**
- Drag-drop canvas
- Element palette
- Property panel
- Save/load layouts
- Operator panel (state buttons)

---

## 4. UI/UX Designer

**Focus:** Visual design system

**Skills:**
- Sci-fi interface aesthetics
- Color theory for state indication
- Touch-friendly interface design
- Animation timing
- Theme system design

**Responsibilities:**
- Color palettes (normal, alert, active, damaged)
- Component specifications
- Touch interaction patterns
- Sample layout designs
- Multiple theme support

---

## 5. Product Owner

**Focus:** Requirements and priorities

**Skills:**
- Video production workflow knowledge
- Non-technical user advocacy
- Feature prioritization

**Responsibilities:**
- Define screen layout requirements
- Prioritize MVP vs v2 features
- Validate acceptance criteria
- Coordinate with production crew

---

## 6. QA Tester

**Focus:** Multi-screen reliability

**Skills:**
- Real device testing
- Network condition simulation
- Performance measurement
- Cross-browser testing

**Responsibilities:**
- Test 6-15 simultaneous screens
- Validate <100ms state sync
- Test touch responsiveness (<50ms)
- Network failure scenarios
