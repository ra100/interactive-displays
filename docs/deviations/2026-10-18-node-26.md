# Node 26 and the latest toolchain

## Date

2026-10-18

## Original Plan

The plan runs the Docker image on `node:24-slim`; the repository asked for Node >= 22.18 and pnpm 9, with
TypeScript 5, Vite 7 and Vitest 4.

## What Changed

- Node 26 everywhere: `engines`, CI and the Docker image (`node:26-slim`).
- pnpm 12. Node 25 stopped shipping corepack, so the Dockerfile installs pnpm with npm at the version named in
  `packageManager`.
- Every dependency moved to its latest release, among them TypeScript 7 (the native compiler), Vite 8, Vitest 5,
  jsdom 30, knip 6 and Zod 4.6.
- TypeScript 7 checks side-effect imports, so the themes package declares `*.css` modules (`src/css.d.ts`).
- Zod 4.6 writes a union of plain types as `type: ["number", "string"]` in JSON Schema; the inspector's field
  describer reads that form as well as `anyOf`.

## Justification

Keeping current on the runtime and tools. Node 26 runs the server's TypeScript with no flags or warnings.

## Impact

Contributors need Node 26 and pnpm 12. Nothing is transpiled for Node: the server and the Playwright config run as
TypeScript directly, and `tsc` only type-checks (`noEmit`). Vitest still transforms test files itself. The app is still built by Vite,
because browsers cannot run TypeScript or JSX and the app is bundled with its CSS and fonts.
